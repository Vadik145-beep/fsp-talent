## Вариант 2. Создать свой аккаунт

1. На экране входа нажать «Зарегистрироваться».
2. Выбрать, кто вы: «Ищу работу» (соискатель) или «Ищу специалистов» (рекрутер — ещё указать название компании). Ввести свою почту и пароль.
3. Открыть письмо на почте и перейти по ссылке подтверждения.
4. Войти со своей почтой и паролем.

Соискатель после входа проходит опрос и тест — по ним получает категорию.

## ФСП ID — тестовый, не настоящий

Настоящий ФСП ID организаторы не подключали: API и данные ФСП в хакатоне не выдаются. Вместо него
работает наш тестовый Keycloak — так будет устроен будущий ФСП ID — и тестовый реестр достижений.
**Ваш настоящий аккаунт ФСП здесь не подойдёт.** Подходят только учётки из таблицы ниже.

Входить на платформу — по почте и паролю. ФСП ID нужен только, чтобы привязать к профилю
соискателя достижения ФСП. Кнопкой «Войти через ФСП ID» на экране входа не пользуйтесь.

### Привязать ФСП ID к своему соискателю

1. Войти своим соискателем (созданным через «Зарегистрироваться»).
2. В кабинете открыть «Достижения ФСП» → нажать «Привязать ФСП ID».
3. Откроется окно входа ФСП ID — ввести логин и пароль из таблицы.
4. Вернётесь в кабинет, достижения ФСП появятся в профиле.

| Логин ФСП ID | Пароль | Что у него есть |
|---|---|---|
| fsp.free01 | Fsp-demo-2026 | есть достижения ФСП |
| fsp.free02 | Fsp-demo-2026 | есть достижения ФСП |
| fsp.free03 | Fsp-demo-2026 | есть достижения ФСП |
| fsp.free04 | Fsp-demo-2026 | есть достижения ФСП |
| fsp.free05 | Fsp-demo-2026 | есть достижения ФСП |
| fsp.free.nohistory | Fsp-demo-2026 | нет истории ФСП |

Одна учётка привязывается только к одному профилю. Если пишет «уже привязан к другому профилю» —
