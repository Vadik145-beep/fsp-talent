# Приложение к разделу 6. Эндпоинты API по ролям

<!-- Файл сгенерирован: python docs/solution/tools/gen_api_table.py. Не править руками. -->

Источник — `docs/api/openapi.json` (fsp-talent API 0.1.0, OpenAPI 3.1.0); роль — по зависимостям в коде роутеров `backend/app/**/router.py`. Подробные схемы запросов и ответов, примеры и описания кодов ошибок — в Swagger `/api/docs`.

Всего методов: **118**.

| Кто вызывает | Методов |
|---|---|
| без входа | 20 |
| реестр ФСП (HMAC-подпись) | 1 |
| любой вошедший | 3 |
| соискатель | 35 |
| рекрутер | 34 |
| админ | 31 |

Метод, доступный двум ролям, учтён в обеих строках. «Без входа» — публичные методы (регистрация, вход, справочники, health). «Любой вошедший» — нужен JWT, роль не важна. Метод с двумя ролями отдаёт каждой свою проекцию данных (например, приглашения: кандидат — полученные, рекрутер — своей компании).

## Коды ошибок

Тело любой ошибки: `{"code": "...", "message": "...", "details": {...}}`. `code` — машинный код (англ.), `message` — текст для пользователя (рус.), `details` — подробности (поля с ошибками, id объекта, дата, когда действие станет доступно).

| HTTP | code | Пример сообщения | Методов |
|---|---|---|---|
| 400 | `oidc_error` | Ошибка входа через ФСП ID: state истёк/подменён, код не принят или ID-токен не прошёл проверку (причина в details.reason) | 2 |
| 400 | `token_invalid` | Ссылка недействительна | 2 |
| 401 | `invalid_credentials` | Неверная почта или пароль | 1 |
| 401 | `invalid_refresh_token` | Сессия истекла, войдите снова | 1 |
| 401 | `invalid_signature` | Неверная подпись вебхука | 1 |
| 401 | `unauthorized` | Требуется вход | 97 |
| 401 | `webhook_expired` | Событие устарело (sent_at старше 5 минут) | 1 |
| 403 | `email_not_verified` | Подтвердите почту по ссылке из письма | 1 |
| 403 | `forbidden` | Недостаточно прав | 94 |
| 403 | `user_blocked` | Учётная запись заблокирована | 2 |
| 404 | `company_invite_not_found` | Код приглашения в компанию не найден | 1 |
| 404 | `fsp_account_not_linked` | ФСП ID не привязан ни к одному профилю | 1 |
| 404 | `not_found` | Объект не найден | 63 |
| 409 | `already_applied` | Вы уже откликнулись на эту вакансию | 1 |
| 409 | `already_invited` | У кандидата уже есть активное приглашение | 1 |

| 409 | `consent_required` | Согласие на обработку ПДн обязательно; удалите аккаунт | 1 |
