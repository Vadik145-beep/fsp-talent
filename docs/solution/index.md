## Решение в пяти пунктах

1. **Обратная механика подбора.** Работодатель описывает потребность, получает подборку
   по категориям (специализация × грейд) с объяснением «почему в подборке» и сам приглашает
   кандидата с обязательной зарплатной вилкой. Контакты открываются только после принятия
   приглашения. Квота приглашений, запрет вилки ниже ожиданий кандидата, отказ с причиной,
   рыночная подсказка «обычно принимают от X ₽».
2. **Категорию определяет тест, а не резюме.** Опрос → выбор грейда → адаптивный тест (IRT, CAT)
   на банке из 192 параметрических шаблонов. Грейд принудительно не понижается, смена — не чаще
   раза в 90 дней.
3. **Тест устойчив к утечкам.** У каждого кандидата свой вариант задачи, сложность шаблонов
   измерена и калибруется по ответам, детектор утечек автоматически выводит «слитые» задачи.
   Нейросеть только предлагает черновики заданий по тексту вакансии — оценку она не делает.
4. **Подтверждённый профиль.** Достижения ФСП приходят из реестра через привязку ФСП ID
   (Keycloak, OIDC), превращаются в бейджи и ФСП-скор и входят в ранжирование. Кандидат без
   истории ФСП не штрафуется.
5. **Проверено на данных с известным ответом.** На 1200 синтетических кандидатах тест
   восстанавливает уровень с корреляцией 0,94 и ставит верную категорию в 78,8% случаев
   (ошибка больше чем на грейд — 0%; заявленный грейд верен лишь в 64,9%). Подбор даёт
   precision@10 0,486 против 0,253 у поиска по ключевым словам резюме. Параметризация снижает
   выгоду от утечки 20% банка с 39% до 12,7% завышенных грейдов. Жюри может загрузить свои
   пары и получить метрики.

## Документ одним файлом (DOCX и PDF)

Готовые файлы: [`fsp-talent-documentation.pdf`](fsp-talent-documentation.pdf) и
[`fsp-talent-documentation.docx`](fsp-talent-documentation.docx) — все разделы в порядке
оглавления, с титульным листом, оглавлением, диаграммами и графиками валидации.

Разделы написаны в Markdown с диаграммами mermaid. Сборка (нужны Node.js для mermaid-cli
и Docker для pandoc и LibreOffice):

```bash
python docs/solution/tools/gen_api_table.py      # таблица раздела 6 из openapi.json
python docs/solution/tools/gen_libraries.py      # раздел 7 (при поднятом docker compose)
python docs/solution/tools/build_docs.py         # → docs/solution/fsp-talent-documentation.{docx,pdf}
```

`build_docs.py` склеивает разделы (`build_bundle.py --render-mermaid`: диаграммы → PNG,
ссылки между разделами → якоря, остальные ссылки → GitHub), конвертирует в DOCX через pandoc
и обновляет оглавление и экспортирует PDF в LibreOffice.
