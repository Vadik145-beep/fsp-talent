## Как перезаписать

Нужны Node.js 20+, пакет `playwright` с Chromium и Docker (для ffmpeg).

```bash
# пакет playwright: свой (npm i playwright && npx playwright install chromium) или путь через PW_MODULE
export PW_MODULE=/путь/к/node_modules/playwright
OUT=/tmp/demo-out     # видео, разметка и state.json между фазами

node docs/demo/record_demo.cjs register  --out $OUT   # новый соискатель (почта demo.video.<время>@example.com)
node docs/demo/record_demo.cjs candidate --out $OUT   # онбординг и тест — см. ниже про ответы
node docs/demo/record_demo.cjs recruiter --out $OUT   # потребность, подборка, профиль кандидата
node docs/demo/record_demo.cjs invite    --out $OUT   # приглашение с вилкой
node docs/demo/record_demo.cjs accept    --out $OUT   # соискатель принимает, рекрутер видит контакты
node docs/demo/record_demo.cjs apply     --out $OUT   # отклик на вакансию
node docs/demo/record_demo.cjs admin     --out $OUT   # банк задач и валидация (только чтение)

node docs/demo/edit_demo.cjs --out $OUT --dst /путь/fsp-talent-demo.mp4
```

Фазы идут по порядку и передают друг другу почту соискателя, его псевдоним и id через `$OUT/state.json`. Упавшую фазу можно перезапустить отдельно. Повтор фаз `register`, `recruiter`, `invite` и `apply` создаёт на стенде новые данные: соискателя, потребность, приглашение, отклик.

**Ответы в тесте.** Правильные ответы кандидату не приходят, поэтому тест проходит человек: на каждой задаче скрипт пишет `$OUT/q_<N>.json` (условие, варианты, код) и ждёт `$OUT/a_<N>.json`:

```json
{"choice": [0, 2]}       // номера вариантов, с нуля
{"text": "16 16 16 16"}  // вывод кода или короткий ответ
{"raw": "42"}            // число
{"line": 13}             // строка с ошибкой
{"order": ["c", "g", "b"]}  // id шагов по порядку
{"skip": true}           // «Не знаю»
```

Если ответа нет, пока на задачу не кончилось время (минус 20 с), скрипт нажимает «Не знаю». Время ожидания помечается для вырезки и в видео не попадает.

**Склейка.** `edit_demo.cjs` читает `$OUT/<фаза>.events.json`: `cut_start`/`cut_end` — вырезать, `speed_start`/`speed_end` — ускорить, `title` — титр (по ним печатаются таймкоды), `hold` — заморозить последний кадр фазы. Разметку можно править руками и пересобрать видео без новой записи. ffmpeg запускается в Docker (`linuxserver/ffmpeg`, другой образ — через `FFMPEG_IMAGE`). Сначала каждая фаза перекодируется в H.264 с ключевым кадром каждую секунду, потом режутся куски, и всё склеивается без перекодирования. `--dry` только печатает длительность и таймкоды.
