# Разбор PDF-резюме (T3.2)

Образцы: `data/samples/resumes/` (5 PDF разной вёрстки, эталон в `*.expected.json`). Режим — правила (pdfplumber + справочник синонимов, без LLM). Страницы в две колонки определяются по вертикальному просвету и режутся по колонкам. Стаж считается на 01.10.2026. Отчёт генерирует `python -m app.nlp.validation`; пороги проверяет `backend/tests/test_resume_parsing.py`.

## Точность по полям (5 резюме)

| Поле | Метрика | Значение |
|---|---|---|
| full_name | доля верных | 100% |
| email | доля верных | 100% |
| phone | доля верных | 100% |
| city | доля верных | 100% |
| specialization | доля верных | 100% |
| grade | доля верных | 100% |
| experience_years | доля верных | 100% |
| work_format | доля верных | 100% |
| links | доля верных | 100% |
| stack | precision / recall (среднее) | 100% / 100% |
| roles | precision / recall | 92% / 100% |
| soft_skills | precision / recall | 94% / 100% |

Сравнение: ФИО, почта, город — без учёта регистра; телефон — `+7XXXXXXXXXX`; стаж — ±0,5 года; формат — первый из найденных (приоритет удалёнка → гибрид → офис); стек — множества кодов после справочника синонимов (технологии вне справочника платформы считаются по `unmatched_skills`); роли и софт-скиллы — мягко, по основе первого слова.
